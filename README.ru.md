# Сказ

Русская версия [Paperclip](https://github.com/paperclipai/paperclip) с подключением
агентов к локальному или корпоративному OpenAI-совместимому серверу.
Исходная лицензия MIT и сведения об авторстве сохранены в `LICENSE`.

## Запуск

Нужны Node.js 24.11+ и pnpm 9.15.4 через Corepack:

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm skrepka
```

При первом запуске команда устанавливает закреплённую версию Pi 0.74.0 в
`.paperclip-local/pi`. После установки зависимостей интернет для самого запуска
и обращений к локальной модели не нужен. Встроенная база, секреты и файлы
экземпляра находятся в `.paperclip-local/state`; каталог исключён из Git.
Адрес приложения по умолчанию: `http://localhost:3100`.

В первом мастере запуска создайте организацию и агента, затем укажите
данные локального или корпоративного API:

- URL API: например `http://localhost:11434/v1` для Ollama или
  `http://localhost:1234/v1` для LM Studio. Допустим корпоративный HTTPS-адрес.
- Модель: точный идентификатор установленной на сервере модели.
- Ключ API: ключ корпоративного сервера. Для сервера без авторизации оставьте
  поле пустым. Ключ сохраняется через существующее хранилище секретов.

Проверка подключения выполняет реальный запрос к выбранной модели. Во время
работы Pi использует тот же адрес и умеет читать и изменять файлы, выполнять
команды, продолжать сессии. Модели нужен корректный вызов инструментов через
Chat Completions. В vLLM включите `--enable-auto-tool-choice` и подходящий
модели `--tool-call-parser`.

URL должен быть абсолютным HTTP(S)-адресом без логина, пароля, query и fragment.
Для корпоративного центра сертификации используйте штатную переменную Node.js
`NODE_EXTRA_CA_CERTS=/absolute/path/to/ca.pem`, сохраняя проверку TLS.

При запуске сервера в контейнере `localhost` обозначает контейнер. Укажите адрес,
по которому сервер модели доступен из среды выполнения агента.

## Что изменено

Локальный API использует существующий адаптер `pi_local` и отдельную конфигурацию
провайдера для каждого агента. Подписок и входа во внешние AI-сервисы не требуется.
Другие исполнители и внешние AI-провайдеры отключены в интерфейсе и на сервере.
Создание и запуск агентов допускаются только через настроенный локальный API.

Телеметрия и загрузка внешних объявлений выключены по умолчанию. Команда
`pnpm skrepka` также явно отключает обе функции. Внешние интеграции, MCP-серверы
и инструменты, которые вы включите сами, могут обращаться в сеть.

Русский выбран по умолчанию. Переключатель «Русский / English» находится в меню
учётной записи. Полностью переведены первый мастер запуска, начальная беседа,
навигация, вход и настройка локального подключения;
часть внутренних страниц и сообщений upstream пока остаётся на английском.

Полная upstream-команда `pnpm build` собирает также необязательный Rust Runner
и требует Rust/Cargo. Для разработки с локальным API он не используется.
В этом форке агенты используют только локальный Pi. Выбор Rust Runner и
внешних подписок исключён.
